# Responsive Blog Card — HTML & CSS

This project is a basic **HTML and CSS challenge** from [GreatFrontEnd](https://www.greatfrontend.com/), where I created a **responsive blog card** based on the provided design. The main goal of this challenge was to practice fundamental frontend development skills such as semantic HTML, CSS styling, Flexbox, spacing, typography, borders, backgrounds, and responsive design. The project was built using only **HTML and CSS**, without any JavaScript or external frameworks.

**Challenge:** [Responsive Blog Card with HTML & CSS](https://www.greatfrontend.com/projects/s/responsive-blog-card-design-with-html-and-css-dc88b3de)

**Live Demo:** https://port10.cldprojects.uk/blog-card/
